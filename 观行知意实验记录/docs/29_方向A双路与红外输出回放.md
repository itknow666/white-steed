# 方向 A · 双路与红外输出回放

上一轮正常双路恢复能找回部分原图正确数，同时降低了只读红外时的准确率。这轮从同一份隐藏 25% 的最佳候选继续训练。保持原模型的两路输入和原预测接口，训练时把教师的 40 类分布作为附加目标。两个冻结教师分别做一项任务。

| 方案 | 双路教师 | IR 教师 |
|---|---|---|
| recovery-control | 无 | 无 |
| clean-replay | 当前原图最佳双路模型 | 无 |
| ir-replay | 无 | 本轮训练起点，关闭深度 |
| both-replay | 当前原图最佳双路模型 | 本轮训练起点，关闭深度 |

每组均以官方 1995 段训练，两轮、batch 8、种子 42、基础学习率 2e-5。优化范围为两个输入残差适配器，学习率倍率为 10。所有组学习真实动作标签。教师读取和学生完全相同的当前训练片段，包括同一次增强与 Mixup。双路回放作用于整批，KL 权重为 0.6。IR 回放取每批的隔位样本，教师和学生都关闭深度，KL 权重为 0.2。温度统一为 2，损失乘温度平方。教师不反传，也不进入部署。

CUDA 检查确认起点的 IR 掩码输出与同权重 IR 教师逐项一致。双路最佳教师在相同片段上的输出与起点不同。蒸馏用于保留旧任务输出的思路参考 [Learning without Forgetting](https://arxiv.org/abs/1606.09282)。本轮只用比赛提供的深度与红外画面。

## 复现

    $py = '.\.venv\Scripts\python.exe'
    $out = 'runs/v8-view-replay-20261123'
    $warm = 'runs/v8-modality-dropout-20261123/adapter-moddrop/best_ema.pt'
    $base = 'runs/v8-teacher-transfer-20261122/kd-non-target/best_ema.pt'
    $common = @('--mode','dual','--continue-dual','--adapter-only','--base-lr','2e-5','--epochs','2','--seed','42','--cache','cache/crop16-192-v3','--initial',$warm)
    & $py optimized/train_domain_v8.py @common --output "$out/recovery-control"
    & $py optimized/train_domain_v8.py @common --replay-clean-teacher $base --output "$out/clean-replay"
    & $py optimized/train_domain_v8.py @common --replay-ir-teacher $warm --output "$out/ir-replay"
    & $py optimized/train_domain_v8.py @common --replay-clean-teacher $base --replay-ir-teacher $warm --output "$out/both-replay"
    & $py optimized/eval_view_replay_v8.py --runs $out --output submission/v8-view-replay-20261123

以 466 段公开验证原图的准确率和 Macro F1 选型。用同一验证集的缓存分别给完整双路、深度、红外，比较各组单路依赖。
