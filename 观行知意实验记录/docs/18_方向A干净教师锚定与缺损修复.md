# 方向 A · 干净教师锚定与缺损特征修复

从 73.61% 的非目标蒸馏轻量版权重出发，同时把这份权重冻结为教师。各训练组使用 1995 段公开训练数据、batch 8、两轮、种子 42、基础学习率 4e-6。学生学习真实动作标签，并使分类分数靠近教师在配对干净视图上的分数。该项用温度 2 的 KL，权重为 0.60。

| 方案 | 附加变化 |
|---|---|
| `anchor-clean` | 正常增强后学习动作标签和冻结教师的分类分数。 |
| `anchor-depth` | 深度缺损组，受损视图匹配同一批干净视图的教师分数，每批所有视图均参与锚定。 |
| `patch-repair` | 在 `anchor-depth` 基础上，用权重 0.20 在缺损位置对齐干净融合特征。目标取冻结教师的时空小块特征，按实际缺损覆盖比例加权。 |
| `anchor-replay` | 在 `anchor-clean` 基础上复用旧的双教师训练缓存，加入权重 0.35 的非目标蒸馏。 |
| `patch-only` | 使用修复目标，仅更新深度与 IR 输入投影及残差适配器，冻结其余参数。 |
| `replay-no-drop` | 与 `anchor-replay` 配方相同，训练时关掉学生的 Dropout 和 DropPath，使学生和教师采用相同的前向模式。 |
| `half-depth` / `half-repair` | 将受损视图训练后的权重分别与训练起点等权平均。 |
| `repair-replay` | 将 `patch-repair` 和 `anchor-replay` 等权平均，合成一份权重。 |
| `clean-depth-mixture` | 在 `replay-no-drop` 完成后补测，将它与 `half-depth` 等权平均。 |

深度训练缺损与上轮相同，在 55% 的训练片段生成随机矩形，边长为画面的 18%–34%，每段沿用同一位置。教师读取扰动前的同一视图，包括相同的裁剪和 Mixup。修复直接约束两路相加后的特征，推理沿用原来的单个双路 VideoMAE。

正式比较用正常 466 段原图，准确率优先、Macro F1 次之。额外在同样的 466 段裁剪缓存上测三种合成扰动，分别为 IR 亮度减半、深度中央边长 40% 的均值填充、以及中间半段帧内右上方的黑色缺损。缓存压力测试用于比较分类器对不同故障形式的敏感性。

冻结教师思路参考 [Learning without Forgetting](https://arxiv.org/abs/1606.09282)。受损特征重建借鉴 [Masked Video Distillation](https://openaccess.thecvf.com/content/CVPR2023/papers/Wang_Masked_Video_Distillation_Rethinking_Masked_Feature_Modeling_for_Self-Supervised_Video_CVPR_2023_paper.pdf)。本轮使用比赛提供的深度与 IR 训练集。

## 复现

```powershell
$py = '.\.venv\Scripts\python.exe'
$runs = 'runs/v8-anchor-repair-20261122'
$out = 'submission/v8-anchor-repair-20261122'
$common = @('--mode','dual','--continue-dual','--base-lr','4e-6','--epochs','2','--seed','42','--cache','cache/crop16-192-v3','--initial','runs/v8-teacher-transfer-20261122/kd-non-target/best_ema.pt','--anchor-weight','.60')
$depth = @('--sensor-augment','--sensor-kind','depth-only')
& $py optimized/train_domain_v8.py @common --output "$runs/anchor-clean"
& $py optimized/train_domain_v8.py @common @depth --output "$runs/anchor-depth"
& $py optimized/train_domain_v8.py @common @depth --patch-repair-weight .20 --output "$runs/patch-repair"
& $py optimized/train_domain_v8.py @common --teacher-cache runs/v8-teacher-transfer-20261122/teacher-train.npz --teacher-policy non-target --output "$runs/anchor-replay"
& $py optimized/train_domain_v8.py @common @depth --patch-repair-weight .20 --patch-only --output "$runs/patch-only"
& $py optimized/train_domain_v8.py @common --teacher-cache runs/v8-teacher-transfer-20261122/teacher-train.npz --teacher-policy non-target --anchor-eval-student --output "$runs/replay-no-drop"
& $py optimized/eval_anchor_repair_v8.py --runs $runs --output $out
& $py optimized/eval_anchor_repair_v8.py --runs $runs --output $out --probe-only
```
