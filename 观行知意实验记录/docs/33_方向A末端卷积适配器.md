# 方向 A · VideoMAE 末端卷积适配器

固定官方训练集、16 帧与 192×192 人物裁剪。从现有 73.61% 双路权重开始，在 VideoMAE 的第 10 与第 12 块后各加一个宽度为 32 的残差适配器。输出投影从零开始。输入的原有空间与时间位置编码保持不变。参考 ST-Adapter 的低维通道逐组卷积思路，比较邻域信息是否能帮助这份已迁移的视频模型。[ST-Adapter 论文](https://proceedings.neurips.cc/paper_files/paper/2022/hash/a92e9165b22d4456fc6d87236e04c266-Abstract.html)

| 名称 | 卷积核（时间×高×宽） | 对照用途 |
|---|---|---|
| latepoint | 1×1×1 | 只对每个时空块分别转换，提供新增参数的对照 |
| latespatial | 1×3×3 | 同一时间位置内比较空间邻域 |
| latetemporal | 3×1×1 | 比较同一空间位置的相邻时段 |
| latejoint | 3×3×3 | 同时读取时间与空间的邻域 |

每组在同一批 1,995 段训练视频上训练两轮，batch 8，两个随机种子为 42 和 43。保留原动作损失、增强、Mixup、EMA 与原来仅由训练集生成的非目标蒸馏缓存。蒸馏温度 2，损失系数 0.35。冻结策略只更新两个新增模块，关闭骨干的随机丢弃，基础学习率 2.4e-5。全量微调策略沿用 6e-6 及原随机丢弃设置。两种策略的适配器均使用 2.5 倍学习率。每种策略内用自己的单点组衡量邻域作用，两种策略间的差异同时含冻结范围、基础学习率和随机丢弃。

共有 16 个新适配器训练组。种子 42 的普通无适配器续训使用已完成的 192 对照，种子 43 独立训练普通续训组。CUDA 检验使用三个真实缓存片段，验证四个新增模型在 FP16、BF16 的初始分数逐项等于起点模型，新增模块可反传。两个卷积模块共增加约 5.16 万至 5.33 万推理参数。推理只用单个分类器和本地人物裁剪。

## 复现

    $py = '.\.venv\Scripts\python.exe'
    $root = 'runs/v8-late-adapters-20261123'
    $out = 'submission/v8-late-adapters-20261123'
    $common = @('--mode','dual','--continue-dual','--initial','runs/v8-teacher-transfer-20261122/kd-non-target/best_ema.pt','--teacher-cache','runs/v8-teacher-transfer-20261122/teacher-train.npz','--teacher-policy','non-target','--teacher-weight','0.35','--epochs','2','--batch','8','--cache','cache/crop16-192-v3')
    foreach ($seed in 42,43) {
        $runs = if ($seed -eq 42) { $root } else { "$root/seed43" }
        $packages = if ($seed -eq 42) { $out } else { "$out/seed43" }
        $arms = @()
        if ($seed -eq 43) {
            & $py optimized/train_domain_v8.py @common --seed $seed --base-lr 6e-6 --output "$runs/plain-control"
            $arms += @('--arm','plain-control')
        }
        foreach ($scope in 'frozen','full') {
            $policy = if ($scope -eq 'frozen') { @('--base-lr','2.4e-5','--late-adapters-only') } else { @('--base-lr','6e-6') }
            foreach ($variant in 'latepoint','latespatial','latetemporal','latejoint') {
                $name = "$scope-$variant"
                & $py optimized/train_domain_v8.py @common @policy --seed $seed --domain-variant $variant --output "$runs/$name"
                $arms += @('--arm',$name)
            }
        }
        & $py optimized/eval_late_adapters_v8.py --seed $seed --runs $runs --output $packages @arms
    }

## 高学习率补测

四个冻结组的初步缓存预测均与原模型逐段一致。追加 4 个训练组来检验学习率的影响。每个种子分别复跑冻结单点和冻结联合适配器，基础学习率由 2.4e-5 增至 9.6e-5，实际新模块学习率为 2.4e-4。其余设置沿用对应的冻结组。训练输出放在 highlr 和 highlr/seed43 下。评估用 --frozen-lr 9.6e-5，并对种子 43 用 --plain-reference 指向同种子原评测目录中的 plain-control。
