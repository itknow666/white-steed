# 方向 A · 非目标蒸馏复跑与权重平均

以上轮 73.61% / Macro F1 70.12% 的轻量版作为评价基线。训练统一从更早的 `anchor43-half` 开始，复用同一份仅含训练集样本的双教师分数。各组使用深度与 IR、1995 段训练数据、batch 8、三轮、基础学习率 6e-6，蒸馏温度为 2。

| 方案 | 本轮变量 |
|---|---|
| `seed44` | 复跑非目标蒸馏，蒸馏系数仍为 0.35，随机种子改为 44。 |
| `weight-015` / `weight-060` | 固定种子 42，将蒸馏系数改为 0.15 或 0.60。 |
| `last-four` | 保持种子 42 和系数 0.35，只更新最后四个 Transformer 块、末端归一化和分类头。 |
| `average-seed42-43` | 对种子 42 和 43 的最佳检查点等权平均。 |
| `average-seed42-43-44` | 对三个种子的最佳检查点等权平均。 |
| `average-anchor-42` | 对训练前的 `anchor43-half` 和种子 42 的最佳检查点等权平均。 |
| `rescaled-three` | 对三份权重平均，再沿平均方向将相对起点的更新幅度恢复为三个种子更新长度的均方根。比例由检查点计算。 |

全量续训各组仍根据准确率与 Macro F1 选择单组检查点。平均操作比较参数键、形状、类型及固定缓冲，导出同一份单模型格式。各候选用 466 段验证原图复验，按准确率、Macro F1 选择新权重。推理沿用冻结的本地人物检测和 VideoMAE 双路输入。

先用上轮缓存验证的配对预测检查两个种子。两者共同正确 338 段，种子 42 独有正确 5 段，种子 43 独有 2 段。概率等权平均正确 341 段。这条对照仅用于观察预测互补性。

三个种子相对起点的参数更新方向，两两余弦相似度为 0.13–0.16。补做幅度恢复组，检验直接平均时缩小更新幅度对识别的影响。

## 复现

```powershell
$py = '.\.venv\Scripts\python.exe'
$runs = 'runs/v8-distill-stability-20261122'
$common = @('--mode','dual','--continue-dual','--base-lr','6e-6','--epochs','3','--cache','cache/crop16-192-v3','--initial','runs/v8-paper-sprint-20261122/anchor43-half/best_ema.pt','--teacher-cache','runs/v8-teacher-transfer-20261122/teacher-train.npz','--teacher-policy','non-target')
& $py optimized/train_domain_v8.py @common --seed 44 --output "$runs/seed44"
& $py optimized/train_domain_v8.py @common --seed 42 --teacher-weight .15 --output "$runs/weight-015"
& $py optimized/train_domain_v8.py @common --seed 42 --teacher-weight .60 --output "$runs/weight-060"
& $py optimized/train_domain_v8.py @common --seed 42 --last-blocks 4 --output "$runs/last-four"
& $py optimized/eval_distill_stability_v8.py --runs $runs --output submission/v8-distill-stability-20261122
```
