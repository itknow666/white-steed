# 方向 A · 局部双传感器可靠度

上一轮的片段级配比只能给整段使用一套权重。本轮保持已经迁移的 VideoMAE 骨干，改为在 8×14×14 个时空块上分别估计深度和 IR 的缺损分数。每个块含连续两帧及 16×16 空间区域。读取两路冻结后的 384 维特征，拼接后由 24 维瓶颈输出两路缺损分数，共 20,042 个新参数。

令 pD 和 pI 为各自的缺损分数，经 sigmoid 压到 0 至 1。计算 g = 0.5 × (pI − pD)，并使用 (1+g)×深度特征 + (1−g)×IR 特征。两个分数的最后一层起点相同，初始配比等权。小数幅度的融合修正先用 FP32 计算、再转回原特征精度。训练的辅助前向保留原部署路径的位置编码精度。FP16 和 BF16 的 CUDA 核验中，初始化的动作分数逐项与原模型相同。

局部按质量调整两路特征参考 [Confidence-Aware RGB-D Face Recognition](https://openaccess.thecvf.com/content/CVPR2024W/BIOMET/papers/Chen_Confidence-Aware_RGB-D_Face_Recognition_via_Virtual_Depth_Synthesis_CVPRW_2024_paper.pdf) 和 [RGB-D Fusion GAN 的双路置信度](https://openaccess.thecvf.com/content/CVPR2022/papers/Wang_RGB-Depth_Fusion_GAN_for_Indoor_Depth_Completion_CVPR_2022_paper.pdf)。此处用比赛深度和 IR 的模拟缺损位置监督，部署只计算现有双流与一个小质量头。

| 方案 | 可训练部分 | 监督 |
|---|---|---|
| adapters-defect | 原深度、IR 两个残差适配器 | 动作标签 |
| local-task | 新增局部质量头 | 动作标签 |
| local-quality | 新增局部质量头 | 动作标签与模拟缺损位置 |
| local-quality-last | 同 local-quality，取末轮 EMA | 同上 |
| local-quality-conservative | 复用末轮模型，将两路缺损分数在 sigmoid 前共同下移 1.5 | 由末轮权重直接生成 |

三个训练组从同一 V8 权重出发，使用同一训练缓存、1995 段、三轮、batch 8 和随机种子 42。新局部模块和旧适配器的峰值学习率均为 5e-4。所有训练均在 Mixup 后合成缺损。缺损位置由对照同一份增强后的干净输入，按两个模态分别计算发生改变的像素，再汇总到每个时空块的覆盖比例。位置监督使用加权二元交叉熵，权重为 0.15，两个模态的正例系数分别为 8 和 3。

原图预测用于模型选型。缓存诊断额外比较 IR 强度减半、深度中央 40% 边长遮挡，以及位置偏移且只遮挡中间半段的深度异常。记录遮挡内外的缺损分数和分类指标。模拟异常的结果用于解释模型反应。

## 复现

    $py = '.\.venv\Scripts\python.exe'
    $out = 'runs/v8-local-reliability-20261122'
    $shared = @('--mode','dual','--continue-dual','--base-lr','5e-5','--epochs','3','--seed','42','--cache','cache/crop16-192-v3','--initial','runs/v8-teacher-transfer-20261122/kd-non-target/best_ema.pt','--sensor-augment')

## 以同一传感器内的区域为参照

末轮质量头确实识别出一部分深度遮挡，但在同一位置，IR 分支的缺损分数整体偏高，导致双路直接相减后的权重方向与预期相反。在相同末轮权重上，先减去每个时间块、每个传感器的空间平均分，再减去固定余量 0.05，取剩余的正数作为局部缺损强度。均匀变化会被这一步消去，因此仍保留全帧 IR 变暗诊断。
