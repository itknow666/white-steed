# 方向 A · 帧数、分辨率与裁剪几何全组合

总计 12 组，因素为 16/24/32 帧、192/224 裁剪输出及直接缩放/保比例补边。16 帧的两组直接缩放使用上一轮已验证的续训对照。另外 10 组本轮从同一份 73.61% 检查点出发，各训两轮。原始最佳不续训，用作同比参考。

所有训练使用官方 1,995 段、seed 42、batch 8、基础学习率 6e-6、同一份仅来自训练集的非目标蒸馏分数，KL 温度 2、权重 0.35。按原图中同一批人物框取图。保比例组把裁剪后的长边缩到目标尺寸，再居中补零。深度与红外使用相同的空间规则，采样前检查两路帧号逐项匹配。开始时两个模态分别均匀取帧，短片段按既有办法重复索引。

VideoMAE 骨干的空间输入保持 224×224。16 帧保持原位置表，24/32 帧将原来的八个时间位置按时间轴插值到 12/16 个位置，每个空间位置独立插值。时间位置表是缓冲区，学习参数量不变。16 帧迁移前后在 CUDA 样例上的分数逐项相等。32 帧、batch 8 完成有限反向计算，峰值约 4,850 MiB。

原图评估可为同一个片段共享本地 YOLO 裁剪与图片解码。对每个候选抽三段核对标准 Model.predict 接口的 40 个分数。每个包还做单段 Windows Python 套接字拦截检查。最终报告使用全部 466 段原图，记录准确率、固定 40 类 Macro F1、按人物的正确数、以及相对于原最佳的改对和改错。各组采用同一随机种子做筛选。

原始验证片段中，16/24/32 帧设置分别有 89/181/268 段需要重复已有帧位置，平均不同帧数为 15.05/20.62/24.66。增加模型输入长度时，新增的实际画面数量取决于原片段长度。
