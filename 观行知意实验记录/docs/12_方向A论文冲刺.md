# 方向 A · 半小时论文实验

起点为原 V8 双路 Adapter 与 R34 的融合，公开验证原图 72.32% / Macro F1 69.50%。本轮只使用深度与 IR 的比赛训练集更新参数，466 段公开验证仅用于闭环选型。

| 组别 | 假设和改动 |
|---|---|
| transfer43 / transfer44 | 从两份训练过的 V7 VideoMAE 权重迁移到双路 Adapter，检验 V8 是否过于依赖 seed 42 的起点。两组仍用训练随机种子 42。 |
| staged43 | 与 transfer43 用同一 V7 权重。第 1 轮冻结 Transformer 块，第 2 轮解冻末四块。 |
| frozen43 | staged43 的补充对照。两轮都冻结 Transformer 块，仅训练双路输入、归一化和分类头。单模型成绩单独记录。 |
| plain | 从 V8 dual 起步全量续训，作为后三类改动的共同对照。 |
| gate | 两路分别提取特征后，用一个零初始化的权重门给每个时空块调整深度和 IR 的相对贡献。 |
| temporal | 在第 4、8、12 个 VideoMAE 块后加 32 维残差时间 Adapter，使用沿时间维度的深度卷积；初始输出等于原 V8。 |
| masked | 在 gate 基础上对训练片段随机选择一种模态，遮挡约 15% 的时空块，保留另一种模态。 |
| distill | 与 masked 同一遮挡配方，额外用冻结的 V8 看完整画面，提供温度 2 的概率目标。教师只接收当批训练片段。 |
| soup43-v8 / soup43-44 / soup-three | 对同构的双路 VideoMAE 权重做等权平均，分别比较 43 与原 V8、43 与 44、三份一起平均。R34 不参与权重平均。 |
| anchor43-half | 将 seed 43 迁移前的原始模型转换为等价的双路结构，和迁移后模型各取一半权重，测试适度回退能否保留起点的分类能力。 |

每个训练组跑两轮，batch 8。transfer 和 staged43 沿用 V8 的 2e-5 学习率，V8 续训各组用 1e-5。新模块从零残差开始，继承其余权重。gate、masked 与 distill 共用初始化与训练顺序。先按单模型公开验证准确率和 Macro F1 选检查点，再固定用 0.75 VideoMAE + 0.25 R34 比较融合。将未迁移的 V7 seed 43、44 同样与 R34 融合作为诊断对照。对本轮新组别，以公开准确率优先、Macro F1 次之选择原图复验对象。

时间 Adapter 借鉴了 [ST-Adapter](https://papers.neurips.cc/paper_files/paper/2022/hash/a92e9165b22d4456fc6d87236e04c266-Abstract-Conference.html) 的时域卷积思路；遮挡蒸馏参考 [UNITE](https://openaccess.thecvf.com/content/CVPR2024/papers/Reddy_Unsupervised_Video_Domain_Adaptation_with_Masked_Pre-Training_and_Collaborative_Self-Training_CVPR_2024_paper.pdf) 的完整视图教师思路，采用本任务的深度与 IR 及分类分布。两项均为针对本任务的简化实现。

同构权重平均参考 [Model Soups](https://proceedings.mlr.press/v162/wortsman22a.html)。迁移前后插值借鉴 [WiSE-FT](https://openaccess.thecvf.com/content/CVPR2022/html/Wortsman_Robust_Fine-Tuning_of_Zero-Shot_Models_CVPR_2022_paper.html) 的思路，两端均为本题的深度与 IR 检查点。两种方法都维持单个双路 VideoMAE 的推理参数量。

`v7-source-soup` 对同三个起始种子先做等权平均，再接 R34。这个对照用于观察收益是否已来自跨种子的权重平均本身。

复现使用原 V8 的数据、缓存及 Python/GPU 环境。先运行两组 transfer，再运行其余各组：

```powershell
$py = ".\.venv\Scripts\python.exe"
$common = @('--cache','cache/crop16-192-v3','--mode','dual','--epochs','2','--seed','42')
& $py optimized/train_domain_v8.py @common --initial runs/videomae2_s-v7-seed43-20261114/best_ema.pt --output runs/v8-paper-sprint-20261122/transfer43
& $py optimized/train_domain_v8.py @common --initial runs/videomae2_s-v7-seed44-20261114/best_ema.pt --output runs/v8-paper-sprint-20261122/transfer44
& $py optimized/train_domain_v8.py --cache cache/crop16-192-v3 --mode staged --epochs 2 --seed 42 --initial runs/videomae2_s-v7-seed43-20261114/best_ema.pt --output runs/v8-paper-sprint-20261122/staged43
$adapt = @('--initial','runs/v8-domain-20261122/dual/best_ema.pt','--continue-dual','--base-lr','1e-5')
& $py optimized/train_domain_v8.py @common @adapt --output runs/v8-paper-sprint-20261122/plain
& $py optimized/train_domain_v8.py @common @adapt --domain-variant gate --output runs/v8-paper-sprint-20261122/gate
& $py optimized/train_domain_v8.py @common @adapt --domain-variant temporal --output runs/v8-paper-sprint-20261122/temporal
& $py optimized/train_domain_v8.py @common @adapt --domain-variant gate --mask-rate .15 --output runs/v8-paper-sprint-20261122/masked
& $py optimized/train_domain_v8.py @common @adapt --domain-variant gate --mask-rate .15 --distill .5 --output runs/v8-paper-sprint-20261122/distill
& $py optimized/soup_domain_v8.py
& $py optimized/soup_domain_v8.py --v7-reference
& $py optimized/finish_v8_paper_sprint.py --runs runs/v8-paper-sprint-20261122 --output submission/v8-paper-sprint-20261122
& $py optimized/probe_ir_domain_v8.py --runs runs/v8-paper-sprint-20261122 --baseline runs/v8-domain-20261122/dual/best_ema.pt --cache cache/crop16-192-v3
& $py optimized/train_domain_v8.py --cache cache/crop16-192-v3 --mode staged --keep-blocks-frozen --epochs 2 --seed 42 --initial runs/videomae2_s-v7-seed43-20261114/best_ema.pt --output runs/v8-paper-sprint-20261122/frozen43
```

## 轻量版

`soup_domain_v8.py` 生成的 `anchor43-half/best_ema.pt` 已是单份双路权重。使用 `videomae2_dual_v8` 单分类器和 V8 同样的 16 帧、192 像素输入与人物裁剪。复现打包时，在 `optimized` 可导入的环境中调用 `package_domain_v8.package`，传入实验目录、输出目录和 `{"mode": "anchor43-half", "fusion": false, "architecture": "videomae2_dual_v8"}` 对应的配置字典。

本机推理对照先预热 4 段，再从清单等间隔取 32 段。每段让融合版和单模型各跑一次，两者交替先后顺序，每次在 CUDA 同步后统计完整 `Model.predict` 时间，含读图与人物检测。

详见 [实验结果及原图复验](../runs/v8-paper-sprint-20261122/实验结果.md)。
