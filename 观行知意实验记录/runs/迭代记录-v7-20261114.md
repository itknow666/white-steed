# 迭代 v7（2026-11-14）：VideoMAE V2 ViT-S 及其与 R(2+1)D-34 的融合

## 动机
复盘 v1–v6：R(2+1)D-34 训练集 97.6%、验证集约 66%，过拟合明显；人物裁剪有效（59.87% → 66.31%）。弱类集中在写字、看电视、使用手机、玩游戏、弓步蹲（易被认成深蹲）、阅读文件。原最优 R34+Swin-T 融合为 68.24% / Macro F1 63.04%，参数 94.02M（含检测器），已接近 100M 上限。

## 做法
- 模型：VideoMAE V2 ViT-S，公开预训练权重 `vit_s_k710_dl_from_giant`（HF OpenGVLab/VideoMAE2 distill/；自监督 UnlabeledHybrid + Kinetics-710 微调，不含 CUHK-X；代码 MIT 许可，见 `competition/videomae2-v7/`）。
- 输入改为 4 通道（伪彩深度 RGB + IR），16 帧，192×192，人物裁剪 1.4。
- 训练：25 轮上限，batch 8，lr 1e-4，逐层学习率衰减 0.8，分类头 lr×10，mixup α=0.2，随机擦除 0.1，EMA，早停（patience 6，最少 12 轮）。每轮约 70 秒，显存约 2.7 GB（RTX 5070 Ti Laptop）。
- 融合：VideoMAE-S ×0.75 + R34（control16-v4）×0.25，各自预处理尺寸（192 / 128），共享一次人物检测；权重只在 0.25/0.5/0.75 中选择。

## 结果（公开验证集 466 段，从原图逐段推理，与缓存结果逐段一致）
| 方案 | 准确率 | Macro F1 | 参数（含检测器） | 平均每段延迟 |
|---|---:|---:|---:|---:|
| VideoMAE-S 单模型（seed 42） | 70.60%（329/466） | 66.54% | 24.72M | 179.8 ms |
| VideoMAE-S×0.75 + R34×0.25（新默认） | 71.89%（335/466） | 68.33% | 88.23M | 259.6 ms |
| 原最优 R34 + Swin-T | 68.24%（318/466） | 63.04% | 94.02M | 302 ms |

单模型 3 个随机种子（缓存级评估）：42 → 70.60% / 66.54%，43 → 71.89% / 68.39%，44 → 71.46% / 67.70%；准确率 71.32% ± 0.66%，Macro F1 67.54% ± 0.94%。

弱类变化：弓步蹲 F1 0.31 → 0.53（被认成深蹲 6 段 → 3 段），阅读文件 0.32 → 0.57，写字 0 → 0.33；看电视召回仍为 0，倒饮料→搅拌饮料仍有 4 段混淆。
