# VideoMAE V2 ViT-S 单模型与缓存级融合（2026-11-14）

只用1995段训练集更新参数；466段公开验证集用于逐轮评估与最佳轮选择（与以往各轮做法相同，存在选择偏差）。未读取隐藏测试。

## 设置
- 骨干：VideoMAE V2 蒸馏 ViT-S/16（K710微调，22.09M参数），四通道适配，内部上采样到224，16帧。来源与SHA256见 weights-provenance.json。
- 缓存：cache/crop16-192-v3（与 MViT/X3D/UniFormer 同一份人物裁剪缓存，共享 YOLO11n 检测器 2,624,080 参数）。
- 训练：optimized/train_videomae.py（复制自 train_candidates.py），batch8，lr 1e-4，逐层学习率衰减0.8，头部x10，AdamW wd0.05，DropPath0.1，mixup0.2，同步遮挡0.1，标签平滑0.05，类别权重^-0.25（仅训练集计数），EMA0.99，最多25轮、耐心6。
- 耗时：18轮（第18轮早停）共1156秒，峰值显存2.75GB；最佳第12轮。

## 结果（缓存级，尚未从原图逐段复验）
| 方案 | 准确率 | Macro F1 | 推理参数（含检测器） |
|---|---:|---:|---:|
| 旧最优 R34+Swin-T（原图复验） | 68.24% | 63.04% | 94.02M |
| VideoMAE-S 单模型 | 70.60%（329/466） | 66.54% | 24.72M |
| VideoMAE-S 0.75 + R34 0.25 | 71.89%（335/466） | 68.33% | 88.23M |
| VideoMAE-S 0.75 + Swin-T 0.25 | 71.24% | 67.37% | 52.60M |
| VideoMAE-S .5 + R34 .25 + X3D .25 | 71.46% | 67.52% | 91.29M |

融合权重按固定网格 .25/.5/.75 比较，全部结果见 fusion-v7-cached.json。单模型纯前向（batch1，FP16，16x192输入）约10.6ms，不含读图与检测。
